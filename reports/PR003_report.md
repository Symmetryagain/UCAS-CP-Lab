### 常量合并
我们实现了编译期的常量合并，体现在对代码中直接出现的常量运算，在编译时直接计算出结果。
这里常量运算包括立即数和使用 const 声明的变量。

**实现方法**：在语法分析的表达式以及相关节点上添加属性 `is_const` 和 `value`。如果发现一个表达式节点的所有子节点都是 const，那么就将两者的 value 计算得到该节点的 value。

**实现细节**：
- 在添加节点的 value 属性时，为了方便，使用 c++ 的 `std::variant` 来维护。
- 在处理 `&&` 和 `||` 时，因为需要先处理常量合并，因此把原先的“直接输出生成的 IR”改为“添加 code 属性暂存 IR 代码，然后在父节点处决定如何产生 IR”。
- 为了能够正确处理 const 的变量，需要将 const 变量的值也存入符号表中，并且需要单独拿出一个接口用来给符号表的 `value` 域来赋值。
